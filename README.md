# ผนังห้องเรียน

หน้าเว็บรวมของทั้งห้อง นักศึกษาแต่ละคนเพิ่มหน้าเว็บของตัวเองเข้ามาหนึ่งหน้า

## สิ่งที่ต้องส่ง

ไฟล์ใหม่หนึ่งไฟล์ในโฟลเดอร์ `students/` ตั้งชื่อไฟล์เป็นรหัสนักศึกษาของตัวเอง

```
students/660610001.html
```

ใช้ `TEMPLATE.html` เป็นจุดตั้งต้น คัดลอกเนื้อหาไปวางในไฟล์ใหม่ของตัวเอง แล้วแก้ให้เป็นข้อมูลของตัวเอง

ไฟล์นี้เป็นหน้าเว็บสมบูรณ์ในตัวเอง มี HTML และ CSS อยู่ในไฟล์เดียว จึงเปิดดูจากเครื่องตัวเองได้เลยด้วยการดับเบิลคลิก ไม่ต้องรอขึ้นเว็บ

## กฎข้อเดียวที่ต้องจำ

**แตะเฉพาะไฟล์ของตัวเอง**

| ไฟล์ | แก้ได้ไหม |
|---|---|
| `students/รหัสนักศึกษาของตัวเอง.html` | แก้ได้ เป็นไฟล์ของคุณ |
| `students/` ของคนอื่น | ห้าม |
| `index.html` | ห้าม |
| `style.css` | ห้าม |
| `TEMPLATE.html` | ห้าม |

ทำตามกฎนี้แล้วต่อให้ทั้งห้องเปิด Pull Request พร้อมกันสามสิบคน ทุกอันจะ merge ผ่านหมดโดยไม่ชนกัน เพราะไม่มีใครแก้ไฟล์เดียวกันเลย

## รายชื่อบนหน้าแรกอัปเดตเอง

ไม่ต้องไปเพิ่มลิงก์ชื่อตัวเองใน `index.html` เมื่อ Pull Request ถูก merge แล้ว ระบบจะไล่อ่านไฟล์ในโฟลเดอร์ `students/` และเพิ่มรายชื่อให้เองภายในหนึ่งถึงสองนาที

การที่ไม่มีใครต้องแก้ `index.html` คือเหตุผลที่งานนี้ไม่เกิด conflict

## ข้อกำหนดของเนื้อหา

- มีชื่อ นามสกุล รหัสนักศึกษา และข้อความแนะนำตัวอย่างน้อยสองบรรทัด
- ต้องมีลิงก์กลับหน้าผนัง
- ตั้งค่า `<title>` เป็นชื่อของตัวเอง
- ไม่ใส่ข้อมูลส่วนตัวที่ไม่ต้องการเปิดเผย เพราะเว็บนี้เปิดสาธารณะ

## ตรวจก่อนส่ง

1. ดับเบิลคลิกไฟล์ของตัวเอง หน้าเว็บต้องแสดงผลถูกต้อง
2. ชื่อไฟล์เป็นรหัสนักศึกษา ตัวเลขล้วน ตามด้วย `.html`
3. เปิดดูรายการไฟล์ที่เปลี่ยนใน Pull Request ต้องมีไฟล์เดียวเท่านั้น และต้องเป็นไฟล์ที่เพิ่มใหม่

ถ้าเห็นไฟล์อื่นติดมาด้วย แปลว่าเผลอไปแก้ไฟล์ส่วนกลาง ให้ย้อนไฟล์นั้นกลับก่อนส่ง
